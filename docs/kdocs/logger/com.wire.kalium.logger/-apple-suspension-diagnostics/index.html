AppleSuspensionDiagnostics

object AppleSuspensionDiagnostics

Bounded, process-local observations for investigating suspension with shared files open.

This writes directly to Apple's unified log, never through a file logger. Labels use a closed vocabulary; callers must not pass paths, SQL, account identities or exception messages. Unknown labels become other. Database spans measure API operations, not SQLite VFS locks. A lifecycle stage does not establish that the process may execute, that it has suspended, or that its files are safe for suspension. Delivery is best effort.
