ExistingDatabaseException

class ExistingDatabaseException(val reason: ExistingDatabaseException.Reason, val cleanupUncertain: Boolean = false, cause: Throwable? = null) : IllegalStateException

An existing-store failure. If cleanupUncertain is true, the account owner must retain its lease until process exit: the native driver can lose a connection during partial opening or failed close.
