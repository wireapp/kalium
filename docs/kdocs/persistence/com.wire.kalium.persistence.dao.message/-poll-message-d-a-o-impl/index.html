open suspend override fun recordVote(conversationId: QualifiedIDEntity, pollMessageId: String, vote: PollVoteEntity): Boolean

Stores vote as the voter's current selection when the poll exists and the selection is valid for it: every option belongs to the poll, and a single-answer poll has at most one option. Repeated options are removed. Returns false without storing anything otherwise. A vote older than the stored one is ignored but still valid.
