ApplePreviewHttpEngine

internal class ApplePreviewHttpEngine(resolveAddresses: suspend (String) -> List<String> = ::resolvePreviewHostAddresses, connect: suspend (host: String, address: String, port: Int) -> PreviewAppleConnection = { host, address, port -> NetworkPreviewConnection.open(host, address, port) }) : HttpClientEngineBase

A preview-only HTTP/1.1 engine. URLSession cannot bind its connection to a validated DNS answer, so Network.framework opens a numeric endpoint while Apple's TLS stack verifies the original host.
