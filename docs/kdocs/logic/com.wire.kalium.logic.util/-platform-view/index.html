actual class PlatformView

Native iOS view wrapper used by calling APIs that need a platform rendering surface.

For AVS video calls, the iOS UI owns the UIView lifecycle and passes it through this wrapper. Kalium forwards view to AVS for remote rendering or local camera preview.
