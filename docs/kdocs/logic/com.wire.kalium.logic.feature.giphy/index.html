interface DownloadGifUseCase

Downloads a GIF's Gif.original rendition from Giphy's CDN to a temporary file. Fails if the response isn't a GIF file (GIF87a or GIF89a header), so nothing else is sent as image/gif. Show that file as the preview and pass it to SendGifMessageUseCase, so the GIF is downloaded only once.

interface SendGifMessageUseCase

Sends a downloaded GIF the way web and the old iOS app do: an optional caption text message, then the GIF as an image/gif asset. Receivers need nothing new. Both messages follow the conversation's self-deleting timer.
