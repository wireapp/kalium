Link copied to clipboard
expect suspend fun UserSessionScope.attachRemoteVideoView(participantId: QualifiedID, clientId: String, view: PlatformView): RemoteVideoViewAttachment

Attach an iOS AVSVideoView to one remote client's stream. The caller owns the view lifetime. Different native views remain attached independently, including views of the same stream. Reattaching the same native view and stream returns its existing lease, even through another PlatformView wrapper. Rebinding that view to another stream detaches its previous attachment and invalidates the old lease. If that detach fails, the previous attachment remains owned and the new stream is not attached. If the new attach fails after detach succeeds, that view remains detached. Other views are unaffected. Operations run on the main dispatcher. The caller must detach each returned lease when its view disappears.

internal suspend fun suspendSync(): SyncSuspension

Stop sync and close its WebSocket client before another process may receive this account's events. Legacy push skips clients the backend serves over an open WebSocket, and consumable notifications need a single consumer. The native socket and the backend see the close asynchronously. Sync stays stopped, even for new requests, until resumeSync or until the returned suspension is cancelled. Failure leaves sync running.
