AppleAvsPlatformRuntime

internal object AppleAvsPlatformRuntime

Owns AVS's single process event loop on iOS. The bridge calls setup then run once, under its start lock.

In the app process, AVSFlowManager starts and owns the loop, and wcall only initializes on top of it, as in the native iOS client. Starting wcall's own loop as well makes AVSFlowManager's loop exit at once and drop the process media-system reference. Releasing the last account handle then frees the media system while the media manager's activation observer still uses it.

App extensions never create UIKit media objects. They keep wcall's own loop.
