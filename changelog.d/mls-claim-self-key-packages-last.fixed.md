Establishing an MLS group that must include every member, such as a one-to-one conversation, no longer uses up the key packages of the self user's other clients when another member has none. Their key packages are now claimed only after every other member's claim succeeded. Before, each failed retry took one key package from each of the user's other devices, which could leave them with none, so they could not be added to new groups.
