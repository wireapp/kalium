Added `ConversationScope.getPaginatedFlowOfConversationDetailsWithMembersBySearchQuery` to search joined groups and channels with their members in paged results. It returns `ConversationDetailsWithMembers` and accepts `ConversationMembersQueryConfig` for search, archive, interaction, team, and domain filters. Set `onlySelfTeamAndDomain` to restrict results to the current user's team and domain. This is an additive API change; no migration is required.
